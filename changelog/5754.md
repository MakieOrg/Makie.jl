## ComputePipeline

- **breaking** `nothing` is now treated as a value rather than "nothing changed" in ComputePipeline callbacks. `skip_update` is used to mark values as unchanged instead. `ComputePipeline.log_nothing_skip(true)` can be used to find potentially incorrect return values.
- `return nothing` has been deprecated for initializing multiple outputs in ComputePipeline callbacks. (`return skip_update` can be used for skipping updates of all outputs.)
