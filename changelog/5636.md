## Breaking

- **minor breaking** Reworked cycling internals for better performance when adding many plots. This changes cycling behavior in some edge cases, e.g. when adding plot specs to a `plotlist` after removing plots from a scene/axis or when leaving cycled attributes unset in recipes. This rework also allows `:cycle` to be themed via `theme[:PlotName][:cycle]` and cycled attributes to be overwritten by `theme[:Plot][...]`.
