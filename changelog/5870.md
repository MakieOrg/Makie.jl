## Added

- Added headless OpenGL rendering with GLFW 4 through EGL or OSMesa, including saving figures and obtaining color buffers without a display server.

## Fixed

- Fixed monitor queries on headless systems and reject visible screens before allocating resources when no display server is available.
- Allow GLMakie to precompile and load without OpenGL drivers, while running the rendering precompile workload when an offscreen context is available.
