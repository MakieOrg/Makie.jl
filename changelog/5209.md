## Breaking

- **breaking** Custom implementations of `legendelements(::Plot, legend)` should no longer set `plots` in the `LegendElement`s they create. Custom `LegendElement` structs no longer need to contain `plots`. This is now handled automatically in the parent `LegendEntry`.

## Fixes

- Fixed `Legend` visibility toggling throwing an error with some recipes.
- Fixed `Legend` visibility toggling overwriting `visible` in children. If a recipe sets a child's visibility to false regardless of the parent visibility, then it will remain false when the parent is toggled.
