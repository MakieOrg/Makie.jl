## Nested Attributes

- Added/Extended support for nested attributes to `@recipe ... begin ... end` recipes, `@Block` and `@DocumentedAttributes` with `outer = @attributes begin ... end` blocks. Any attribute defined within this block will be considered nested inside `outer`. The block itself can have a docstring and may include `mixin...` expressions.
- Extended `@inherit` to support callbacks `@inherit callback name default`, fallbacks `@inherit(first_choice, @inherit fallback)` and nesting `@inherit (outer, inner)`.
- Added support for nested attributes to the plot/attribute documentation system. This is now also used for Blocks
- **mildly breaking** Internal attribute processing for plots and blocks has been reworked and merged, which includes the removal of various internal functions. See [#5620 Removed Functions](https://github.com/MakieOrg/Makie.jl/pull/5620)
- Attribute initialization has been reworked and merged, which may fix some unintended differences in theming/attribute defaults. The prioritization is now consistently:
    1. plot/block kwargs
    2. plot/block attribute passthrough (e.g. `plot!(parent, parent.attributes, ...)`)
    3. overwrite themes (e.g. entries in `scene.theme[Scatter/Axis]`)
    4. plot/block defaults (i.e. what's set in `@recipe/@Block/@DocumentedAttributes`) which includes theme-inherited values (e.g. `colormap = @inherit colormap` within `@recipe/@Block/@DocumentedAttributes`)
- Added a deprecation warning to old `@recipe ... do ... end` syntax
- Added support for nested attributes to SpecApi
- Added support for nested attributes in `shared_attributes`
