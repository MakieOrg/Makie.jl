## Internal

- Refactored `Axis` to use the compute graph

## Breaking

- **minor breaking** Custom interactions that manipulated `ax.targetlimits` should now update `ax.localxlimits` and `ax.localylimits` instead and read from either `ax.targetlimits` or `sharedxlimits` and `sharedylimits`. Otherwise they will not correctly update linked axes.

## Changes

- Redisplaying a figure after emptying an axis now resets its limits if they aren't set to specific values.

## ComputePipeline

- Added `ComputePipeline.set_type!(node, type)` for initializing the type of a compute graph node.
- Fixed an issue where Observable outputs of compute nodes that cycle back into the compute graph could discard updates of other Observable outputs.
- Added `ExplicitUpdate` wrapper to control update propagation for computations in the compute graph. Also added `force_update` as a keyword argument in `add_input!` for forcefully propagate updates from input nodes.
