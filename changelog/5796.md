- Updated `series`, `volumeslices` and `rainclouds` to use the compute pipeline infrastructure.
  - `rainclouds` should be much more dynamic now, as most attributes and arguments were previously not reactive.
- Adjusted `volumeslices` to work with color data.
- Adjusted `volumeslices` to generate x, y and z values like e.g. volume.
- Fixed `volumeslices` limits.
- Added `xy/yz/xz_index` attributes to `volumeslices` as an alternative to calling `plot.update_xy[](index)`.
- Adjusted `series` to allow the number of subplots to change dynamically.
- Fixed `series` not accepting `Vector{Vector{<:Real}}`.
- Fixed error on empty `series`.
- Adjusted `series` to cycle colors sampled from `color` if more are needed. This can be controlled by the new `cycle_color` attribute. By default cycling is enabled with a warning.
- Added colormapping to `series`, allowing `color` to be set to values.
