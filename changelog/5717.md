
## Text Refactor

- **breaking** Reworked `text` to make text layouting extendable and adjustable. You can now implement `Makie.layout_text(handler, str, attributes)` methods with a custom `handler` to define how existing or new string types are lowered to glyphs and plot specs. The handler can then be passed to `text` via `text_handler` to route to those methods. If a handler does not implement `layout_text` for a specific string type the default handler will be used as a fallback.
- **breaking** `text` and `pathtext` no longer accept per-character `color`, `strokecolor`, `strokewidth` and `fontsize`. Use `rich` text to style parts of a string. (Attributes still work per-string.)
- **breaking** `text` is a regular recipe now rather than a primitive plot, so reading an attribute off a `Text` gives the value as passed instead of a converted one (`plot.offset` stays a `Point2f` instead of becoming a `Vec3f`, `plot.color` stays `:red`), matching every other recipe. `Glyphs` now acts as the primitive under text.
- **minor breaking** With `justification = automatic`, a fractional `halign` now justifies by that fraction instead of falling back to `0.5`.

## Fixes

- Fixed `visible`, `depth_shift`, `transparency`, `fxaa`, `overdraw` and `inspectable` on `text` being ignored by the GL backends.
- Fixed an axis label, title or subtitle only accepting base `String`s.
- Fixed `rich` text in `pathtext` ignoring the plot's `color` for the parts it doesn't style itself, and `alpha` being applied twice.
- Fixed `align = (halign, :baseline)` aligning `rich` text and `LaTeXString`s to their bottom edge rather than their baseline.

## ComputePipeline

- Fixed `Ref`-wrapped values returned by edge callbacks always marking outputs dirty.
