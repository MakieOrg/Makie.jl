## Render Order

- **breaking** Plots of one scene can no longer draw between plots of another. (Previously plot layering was based on depth globally.)
- Fixed `scene.clear` not erasing content under the `scene`.
- Adjusted CairoMakie's plot sorting to be based on a depth estimate of a plots bounding box. This should improve ordering of 3D plots and fix sorting issues related to only considering `translate!`.
- Adjusted GLMakie and WGLMakie's draw order to be based on the same depth estimates with further biasing based on the plot type and transparency. This should reduce blending artifacts with transparent plots and may improve performance.
- Added `zorder_shift` in Plots to influence the draw order in all backends independently of the plots depth. This can be used to treat blending artifacts and order plots with `overdraw = true`.
- Added `zindex` in Scenes to control the order of scenes in `parent.children`. This can be used to pin an overlay scene before inserting other scenes.
- Fixes layering issues of Axis3 decorations, such as panes covering frame lines and front frame lines showing blending artifacts
