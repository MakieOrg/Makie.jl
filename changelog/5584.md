## Breaking

- WGLMakie now requires Bonito 5.3 and Julia 1.11 or later for session ownership and browser-listener cleanup.

## Changed

- Reduced WGLMakie first-display compilation and Axis construction work, and added an optional full precompile workload.
- Switched WGLMakie browser tests to ElectronCall and enabled rendering on demand by default.

## Fixed

- Figures mounted independently can recover missing glyphs without waiting for an earlier figure to mount.
- Inserting or deleting plots while disconnected no longer blocks; the browser receives a fresh scene snapshot when it reconnects.
- Normalized byte (`N0f8`) volumes upload successfully with Bonito 5.3.
- Cached figures retain correct glyph metrics on fresh pages; reconnects preserve later plot insertions without accumulating scene bindings or render timers.
- Compute callbacks defined after a task starts can resolve from that task, and live rendering errors propagate to callers.
- Notebook outputs removed during asynchronous initialization no longer create WebGL scenes for detached canvases.
- WGLMakie finds its shader sources in relocated (PackageCompiler) apps.
- A figure removed from the page releases its WebGL context as soon as Bonito frees its session; before, contexts piled up until the browser evicted one, which could be the figure still on screen.
- Glyph batches travel on the plot's own session, so an offline page that shows several figures in a row (Documenter, Pluto export) renders all of them.
