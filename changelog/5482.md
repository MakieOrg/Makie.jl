## Nested Attributes

- **breaking** Added support for nested attributed via `key = Attributes(...)` in old `@recipe ... do ... end` recipes. Previously this would add a compute node "key" containing the `Attributes`. Workarounds to keep this syntax working after 0.24 will now be broken as `plot.key` is not a node anymore.

## ComputePipeline

- Added a system for simulating nested nodes. This includes:
    - Nested access, e.g. `graph.outer.inner` and `graph[:outer][:inner]`
    - Nested inputs, e.g. `add_input!(graph, :outer, :inner, val)`, `add_input!(graph.outer, :inner, val)` and `add_input!(graph, (:outer, :inner), val)`
    - Nested edges, e.g. `map!(graph, [(:outer, :inner), ...], (:outer, :output))` and `map!(graph.outer, :inner, :output)` (analogous for `register_computation!`)
    - Nested views, e.g. `graph.outer` will create a `ComputeGraphView` if other nodes are nested under it. These views can also be created with `ComputeGraphView(graph, :outer)` which will add `:outer` as a nesting layer if it does not exist.
