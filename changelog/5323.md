## Dim Converts

- **breaking** most plot recipes now set the target types for their conversions. This means `plot!(::PlotType{<:MyArgTuple})` requires introducing a conversion trait and extending `Makie.types_for_plot_arguments()` to function. See docs.
- **breaking** `UnitfulConversion` no longer rescales units and dropped the `units_in_label` option/field.
- **minor breaking** Added `show_in_label` argument to `get_ticks`. If true, `get_ticks` should add dim convert related information to tick labels. (`show_in_label` is dropped by the default method so that old implementations still work.)
- Added `Makie.argument_dims()` and `Makie.argument_dim_kwargs()` for specifying how arguments map to dim converts, optionally including attributes like `direction`. This adds support for point-like arguments, dimensionless arguments (not dim converted) and multiple arguments using the same dim convert.
- Added `show_dim_convert_in_axis_label`, `show_dim_convert_in_ticklabel` and `get_label_suffix` interface functions for controlling how dim converts interact with tick and axis labels.
- Updated almost every Makie recipe to work with dim converts.
- Added support for x/y/zlabel suffixes based on dim converts via `Axis` and `Axis3` attributes. (This can automatically append `[m]` to a given `xlabel`, for example.)
- Adjusted conversion logic to avoid applying dim converts when `space != :data`. We now also allow early `convert_arguments()` application when dim converts are forced. (I.e. when the parent scene/Axis/etc. has set dim converts.)
- Added `force_dimconverts` as a generic plot keyword argument. This can be set to `false` to allow a numeric plot to plot in a scene with fixed dim converts. (E.g. for axis decorations.)
